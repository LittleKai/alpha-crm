# Product

## Register

product

## Users
Operators and business owners using Alpha CRM to manage customer relations and automate Zalo marketing campaigns. They need to quickly understand their limits, quotas, and subscription details to keep operations running smoothly.

## Product Purpose
Alpha CRM serves Zalo marketing automation. The subscription screen displays current package details, AI credits/quota, and available top-up packages. Success is measured by how easily the operator can assess remaining quota and top-up if necessary without layout confusion.

## Brand Personality
Modern, reliable, and professional. The styling uses a restrained palette, strong typography contrast, and precise alignments. It avoids decorative fluff and focuses on layout clarity.

## Anti-references
- Side-stripe borders (accent lines on cards)
- Gradient text
- Unstructured layout grids with identical visual weights
- Weak contrast text (grey text on tint background)
- Overflowing text on narrow screens

## Design Principles
- **Clarity Over Decoration**: UI elements exist to deliver information, not to fill space.
- **Consistent Spacing Rhythm**: Use the standard spacing scale of the application strictly.
- **Precision Hierarchy**: Size and weight should communicate relative importance clearly.
- **Responsive Resilience**: Components must gracefully adapt to both mobile and desktop sizes.

## Accessibility & Inclusion
- Contrast ratio ≥ 4.5:1 for body text.
- Large targets for touch interaction.
- Support for system font scaling and reduced motion.
