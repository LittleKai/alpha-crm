# Alpha CRM Customer Installation Guide

1. Create or login to your Alpha Studio account on the web portal.
2. Buy or renew an Alpha CRM subscription.
3. Download and install the Windows application on your primary machine.
4. Log in on the Windows application using your Alpha Studio account.
5. Connect your local Zalo account through the app.
6. Register the Windows machine to your subscription.
7. Download and install the Android app.
8. Pair your phone using the QR code or 6-digit code shown on the Windows app.
9. Your setup is complete! Please note your subscription expiry date and AI request quota.

## Using Live Chat on your phone or a web browser

Once paired, Live Chat works on your phone and in Chrome (`giaiphapsangtao.com`) too —
not just on the Windows app. A few things to know:

- Your **Windows machine must stay on and connected** for phone/web Live Chat to work — it
  relays messages to and from Zalo. If it's off or the Zalo session expires, phone/web will
  show a banner and pause sending until it's back online (usually within ~90 seconds of the
  machine coming back).
- New messages appear in under a second when the Windows machine is online; sent messages
  confirm within a few seconds.
- Full chat history stays on the Windows machine. Phone/web only shows messages sent or
  received since pairing.
