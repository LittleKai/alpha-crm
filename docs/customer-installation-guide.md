# Alpha CRM Customer Installation Guide

1. Create or login to your Alpha Studio account on the web portal.
2. Buy or renew an Alpha CRM subscription.
3. Download and install the Windows application on your primary machine.
4. Log in on the Windows application using your Alpha Studio account.
5. Connect your local Zalo account through the app.
6. Register the Windows machine to your subscription.
7. Download and install the Android app.
8. Pair your phone using the QR code or 6-digit code shown on the Windows app.
9. Your setup is complete! Please note your subscription expiry date and AI request quota.
