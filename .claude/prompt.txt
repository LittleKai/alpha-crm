Hãy refactor Alpha CRM Live Chat sang kiến trúc Phương án : Local-first, Cloud minimal.

Mục tiêu:
- Cloud backend alpha-studio-backend chỉ lưu metadata tối thiểu cho CRM Live Chat.
- Không lưu full nội dung tin nhắn trên cloud nữa.
- Local Zalo bridge trong tools/alpha-crm/integration/zalo-bot-service lưu toàn bộ message history vào local DB.
- Flutter Alpha CRM ưu tiên lấy full messages từ local bridge thay vì cloud.

Yêu cầu cụ thể:
1. Cloud backend:
   - Giữ API /crm/conversations để trả danh sách hội thoại nhẹ.
   - Chỉ lưu các field tối thiểu: conversationId, zaloThreadId, threadType, displayName, avatarUrl, lastMessagePreview, lastMessageAt, unreadCount, managedGroup flag, bridgeDeviceId, bridgeOnline.
   - Không lưu body/full payload/raw message/media base64 vào CrmMessage trên cloud.
   - Endpoint /crm/conversations/:id/messages chỉ trả lỗi/empty hoặc redirect logic sang local bridge, tùy cách phù hợp với code hiện tại.
   - Giữ command queue để local bridge poll lệnh gửi tin.

2. Local Zalo bridge:
   - Thêm local SQLite DB hoặc DB nhẹ tương đương để lưu conversations, messages, attachments, sync_state.
   - Khi nhận inbound message từ Zalo, lưu full message vào local DB trước.
   - Chỉ sync metadata/summary lên cloud.
   - Cung cấp local API:
     GET /local/conversations/:id/messages?before=&after=&limit=
     POST /local/messages/send
     GET /local/health
   - Đảm bảo gửi tin vẫn đi qua ZCA/local bridge.

3. Flutter Alpha CRM:
   - Sửa live_chat_repository.dart để:
     - Lấy danh sách conversations từ cloud.
     - Khi mở hội thoại, lấy messages từ local bridge.
     - Nếu local bridge offline, hiển thị trạng thái “Bridge offline, chỉ xem được metadata/recent summary”.
   - Thêm cấu hình localBridgeBaseUrl.
   - Không phụ thuộc cloud message history nữa.

4. Migration:
   - Không xóa code cũ ngay; tách bằng feature flag LOCAL_FIRST_LIVE_CHAT=true.
   - Viết fallback an toàn nếu local bridge chưa sẵn sàng.
   - Cập nhật README/ENV mẫu.
   - Chạy test/lint/build nếu có.

Trước khi sửa code:
- Phân tích kiến trúc hiện tại.
- Liệt kê file cần sửa.
- Sau đó thực hiện từng bước nhỏ, commit-style summary cuối cùng.
