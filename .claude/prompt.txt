## Yêu cầu kỹ thuật Flutter

Khi chỉnh sửa code Flutter:

* Code phải chạy được.
* Không để lỗi compile.
* Không để import thừa nghiêm trọng.
* Ưu tiên widget nhỏ, dễ tái sử dụng.
* Tách file hợp lý.
* Không nhồi toàn bộ UI vào một file lớn.
* Dùng const constructor khi có thể.
* Không dùng magic number quá nhiều.
* Tạo component riêng cho card, sidebar, table, filter, empty state nếu cần.
* Responsive bằng LayoutBuilder, MediaQuery hoặc breakpoint helper phù hợp.
* Giữ code dễ đọc và dễ mở rộng.

## Kiểm tra sau khi hoàn thành

Sau khi sửa, hãy chạy các lệnh phù hợp trong project Flutter, ví dụ:

```bash
flutter pub get
flutter analyze
flutter test
```

Nếu project không có test thì vẫn phải chạy `flutter analyze`.

Nếu có lỗi, hãy sửa lỗi. Nếu có lỗi không thể sửa vì thiếu thông tin hoặc phụ thuộc bên ngoài, hãy ghi rõ trong summary.
